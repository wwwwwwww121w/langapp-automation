🚀 РАЗВЕРТЫВАНИЕ НА RAILWAY - ПОШАГОВАЯ ИНСТРУКЦИЯ
═══════════════════════════════════════════════════════════════════════════════

GitHub репозиторий готов!
Адрес: https://github.com/wwwwwwww121w/langapp-automation

═════════════════════════════════════════════════════════════════════════════
ШАГ 1: ОТКРОЙТЕ RAILWAY.APP
═════════════════════════════════════════════════════════════════════════════

1. Перейди: https://railway.app
2. Нажми: "Login" → "GitHub"
3. Авторизуй Railway для доступа к твоему GitHub

═════════════════════════════════════════════════════════════════════════════
ШАГ 2: СОЗДАЙ НОВЫЙ ПРОЕКТ
═════════════════════════════════════════════════════════════════════════════

1. На главной странице нажми: "+ New Project"
2. Выбери: "Deploy from GitHub repo"
3. Найди и выбери: "langapp-automation"
4. Railway автоматически обнаружит Dockerfile и начнет деплой

═════════════════════════════════════════════════════════════════════════════
ШАГ 3: ДОБАВЬ ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ
═════════════════════════════════════════════════════════════════════════════

1. В Railway Dashboard перейди: Project Settings → Variables
2. Добавь эти переменные (нажми "Add Variable" для каждой):

   TELEGRAM_BOT_TOKEN=<your-telegram-bot-token>
   TELEGRAM_ADMIN_ID=<your-admin-id>
   XAI_API_KEY=<your-xai-api-key>
   XAI_VIDEO_MODEL=grok-imagine-video
   XAI_VIDEO_DURATION=8
   XAI_VIDEO_ASPECT_RATIO=9:16
   XAI_VIDEO_RESOLUTION=720p
   FIREWORKS_API_KEY=<your-fireworks-api-key>

3. Нажми "Deploy" или дождись автоматического деплоя

═════════════════════════════════════════════════════════════════════════════
ШАГ 4: ЖДИ ДЕПЛОЯ (~2-3 МИНУТЫ)
═════════════════════════════════════════════════════════════════════════════

- Railway будет:
  ✅ Скачивать код с GitHub
  ✅ Собирать Docker image
  ✅ Запускать бота в контейнере
  ✅ Предоставлять 24/7 хостинг

- Смотри статус в: Deployments → Logs

═════════════════════════════════════════════════════════════════════════════
ШАГ 5: ПРОТЕСТИРУЙ БОТА В TELEGRAM
═════════════════════════════════════════════════════════════════════════════

После успешного деплоя:

1. Откройте Telegram
2. Найдите бота по username (или используйте ссылку из Railway)
3. Отправьте команду: /start
4. Должно появиться меню с кнопками
5. Нажмите: "🎬 Генерировать видео Grok"
6. Ждите 1-2 минуты (бот генерирует видео)
7. Получите 3 ссылки на видео! ✅

═════════════════════════════════════════════════════════════════════════════
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
═════════════════════════════════════════════════════════════════════════════

1. Проверьте логи:
   - Railway Dashboard → Deployments → Logs
   - Ищите ошибки в консоли

2. Убедитесь что переменные добавлены:
   - Project Settings → Variables
   - Все 8 переменных должны быть добавлены

3. Перезагрузите:
   - Railway Dashboard → Redeploy
   - Это перезапустит бота заново

4. Проверьте ключи:
   - Все ключи должны быть скопированы без пробелов
   - Telegram bot token правильный
   - XAI API key актуален
