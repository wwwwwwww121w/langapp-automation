✅ ВЫБОР 1: RAILWAY.APP (САМЫЙ ПРОСТОЙ) ⭐⭐⭐
═══════════════════════════════════════════════════════════════════════════════

1️⃣ Перейди: https://railway.app

2️⃣ Нажми: "Login with GitHub" → авторизуй

3️⃣ Нажми: "New Project" → "Deploy from GitHub repo"

4️⃣ Выбери: langapp-automation (твой репозиторий)

5️⃣ Добавь переменные окружения:
   - Project → Variables
   - Добавь все из этого списка:

   TELEGRAM_BOT_TOKEN=your-telegram-bot-token-here
   TELEGRAM_ADMIN_ID=your-admin-id-here
   XAI_API_KEY=your-xai-api-key-here
   XAI_VIDEO_MODEL=grok-imagine-video
   XAI_VIDEO_DURATION=8
   XAI_VIDEO_ASPECT_RATIO=9:16
   XAI_VIDEO_RESOLUTION=720p
   FIREWORKS_API_KEY=your-fireworks-api-key-here

6️⃣ Жди деплоя (~2 минуты)

7️⃣ ✅ ГОТОВО! Бот работает 24/7!

Статус: Deployments → смотри логи

✅ ВЫБОР 2: REPLIT.COM (ОЧЕНЬ ПРОСТОЙ) ⭐⭐⭐
═══════════════════════════════════════════════════════════════════════════════

1️⃣ Перейди: https://replit.com

2️⃣ Нажми: "Create" → "Python"

3️⃣ Загрузи:
   - bot/telegram_bot_grok_v3.py
   - .env (со всеми ключами)
   - requirements.txt

4️⃣ В консоли:
   pip install -r requirements.txt
   python bot/telegram_bot_grok_v3.py

5️⃣ Включи "Always on" (платная функция, дешевая)

6️⃣ ✅ ГОТОВО! Бот работает 24/7!

─────────────────────────────────────────────────────────────────────────────

✅ ВЫБОР 3: PYTHONANYWHERE.COM (СВОБОДНЫЙ) ⭐⭐⭐
═══════════════════════════════════════════════════════════════════════════════

1️⃣ Перейди: https://www.pythonanywhere.com

2️⃣ Создай account

3️⃣ Files → загрузи проект

4️⃣ Bash console:
   pip install --user -r requirements.txt

5️⃣ Запусти в фоне:
   python bot/telegram_bot_grok_v3.py &

6️⃣ Web → "Add a new web app"
   - Настрой как "Always on"

7️⃣ ✅ ГОТОВО! Бот работает 24/7!

✅ ЛОКАЛЬНОЕ ТЕСТИРОВАНИЕ (НА СВОЕМ ПК)
═══════════════════════════════════════════════════════════════════════════════

Прежде чем деплоить в облако, протестируй локально:

1️⃣ Установи Docker:
   https://www.docker.com/products/docker-desktop

2️⃣ В папке проекта:
   docker-compose up -d

3️⃣ Проверь работу:
   docker-compose logs -f

4️⃣ Тестирование в Telegram:
   - Отправь /start боту
   - Нажми "🎬 Генерировать видео Grok"
   - Жди 1-2 минуты
   - Получи видео!

5️⃣ Останови:
   docker-compose down
