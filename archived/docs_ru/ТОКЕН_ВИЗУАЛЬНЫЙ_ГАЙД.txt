1️⃣  ПОЛУЧИТЬ ТОКЕН ОТ @BotFather (2 МИНУТЫ)
═══════════════════════════════════════════════════════════════════════

ШАГ 1: Откройте Телеграм

ШАГ 2: В поиске напишите: @BotFather
       (это специальный бот Телеграма для создания ботов)

ШАГ 3: Откройте чат с @BotFather

ШАГ 4: Напишите ему: /newbot
       (и нажмите отправить)

ШАГ 5: @BotFather спросит:
       "Как назвать вашего бота?"
       
       Ответьте: LinguaStart Video Farm
       (или любое другое имя)

ШАГ 6: @BotFather спросит:
       "Выберите юзернейм для бота"
       
       Ответьте: linguastart_farm_123
       (ВАЖНО: должно заканчиваться на _bot и быть уникальным!)

ШАГ 7: @BotFather вам ДАСТ ДЛИННУЮ СТРОКУ, например:
       
       6123456789:ABCDEFGHIJKLMNOPQRSTuvwxyz1234567890
       
       ✅ СКОПИРУЙТЕ ВСЮ ЭТУ СТРОКУ!
          Это ваш ТОКЕН - самое важное!

3️⃣  ОТРЕДАКТИРОВАТЬ ФАЙЛ .env (САМЫЙ ВАЖНЫЙ ШАГ!)
═══════════════════════════════════════════════════════════════════════

ФАЙЛ РАСПОЛОЖЕН ЗДЕСЬ:
📁 C:\langapp-automation\.env

КАК ЕГО ОТКРЫТЬ:

ШАГ 1: 🪟 Откройте Windows Explorer (проводник)
       Нажмите: Win+E

ШАГ 2: 📁 Перейдите в папку:
       C:\langapp-automation       
       (или вручную: C: → langapp-automation)

ШАГ 3: 👁️  Если не видите файл .env:
       
       Нажмите сверху: "Вид" (View)
       Поставьте галочку: "Скрытые элементы" (Hidden items)
       
       Теперь файл .env должен быть виден!

ШАГ 4: 📄 Найдите файл: .env

ШАГ 5: 🖱️  Щелкните по нему ПРАВОЙ кнопкой мыши

ШАГ 6: 📝 Выберите: "Открыть с помощью" → "Блокнот"

ШАГ 7: 📋 В Блокноте откроется текст. Найдите в конце файла:
       
       Строка 1:
       TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
       
       Строка 2:
       TELEGRAM_ADMIN_ID=your_telegram_user_id_here

ШАГ 8: ✏️  ЗАМЕНИТЕ эти строки на ВАШИ ЗНАЧЕНИЯ:
       
       ┌─────────────────────────────────────────────────────┐
       │ БЫЛО:                                               │
       │ TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here     │
       │ TELEGRAM_ADMIN_ID=your_telegram_user_id_here        │
       │                                                     │
       │ СТАЛО (ПРИМЕР):                                     │
       │ TELEGRAM_BOT_TOKEN=6123456789:ABCDEFGHIJK...       │
       │ TELEGRAM_ADMIN_ID=123456789                         │
       └─────────────────────────────────────────────────────┘

ШАГ 9: 💾 Нажмите: Ctrl+S (сохранить файл)

ШАГ 10: ❌ Закройте Блокнот (нажмите кнопку X)

✅ ГОТОВО! ТОКЕН И ID ДОБАВЛЕНЫ!

СПОСОБ 1: САМЫЙ ПРОСТОЙ (РЕКОМЕНДУЕТСЯ)

ШАГ 1: 🪟 Откройте Windows Explorer

ШАГ 2: 📁 Перейдите в папку: C:\langapp-automation

ШАГ 5: ⏳ Появится ЧЕРНОЕ ОКНО (это нормально!)
       Дождитесь сообщения:
       "✅ Bot started successfully!"

ШАГ 6: 📌 НЕ ЗАКРЫВАЙТЕ это окно!
       Пусть оно остается открытым все время работы бота

5️⃣  ПРОТЕСТИРОВАТЬ БОТ (1 МИНУТА)
═══════════════════════════════════════════════════════════════════════

ШАГ 1: 🤖 Откройте Телеграм

ШАГ 2: 🔍 Найдите вашего бота по имени/юзернейму
       (что вы создавали в шаге 1 с @BotFather)
       Например: linguastart_farm_123

ШАГ 3: 💬 Откройте чат с ботом

ШАГ 4: ⌨️  Напишите: /start
       (это команда "начать")

ШАГ 5: 🚀 Нажмите ОТПРАВИТЬ

ШАГ 6: 📨 Если бот ответил сообщением:
       "🚀 Добро пожаловать в LinguaStart..."
       
       ✅ ВСЕ РАБОТАЕТ! БОТ ГОТОВ!

6️⃣  ГЕНЕРИРОВАТЬ ПЕРВОЕ ВИДЕО
═══════════════════════════════════════════════════════════════════════

ШАГ 1: 💬 В чате с ботом напишите: /generate

ШАГ 2: 🤖 Бот спросит: "Сколько видео? (1-20):"

ШАГ 3: ⌨️  Напишите: 1
       (начните с одного видео для теста)

ШАГ 4: 🚀 Нажмите ОТПРАВИТЬ

ШАГ 5: ⏳ БОТ БУДЕТ РАБОТАТЬ 5-10 МИНУТ
       
       Вы увидите сообщения:
       "⏳ Этап 1/3: Генерация сценариев..."
       "⏳ Этап 2/3: Создание кадров..."
       "⏳ Этап 3/3: Монтаж видео..."

ШАГ 6: 📹 Когда закончится, бот отправит вам VIDEO ФАЙЛ
       
       ✅ ПЕРВОЕ ВИДЕО СОЗДАНО! 🎉

⚠️  ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
═══════════════════════════════════════════════════════════════════════

ПРОБЛЕМА: Бот не отвечает на /start
✅ РЕШЕНИЕ:
   1. Проверьте интернет
   2. Закройте и откройте заново start_farm_mode.bat
   3. Убедитесь что открыли ЧАТ С ВАШИМ БОТОМ (не с другим!)
   4. Проверьте файл .env еще раз

ПРОБЛЕМА: Ошибка "TELEGRAM_BOT_TOKEN not found"
✅ РЕШЕНИЕ:
   1. Откройте .env файл в Блокноте
   2. Убедитесь что там есть TELEGRAM_BOT_TOKEN
   3. Убедитесь что там есть TELEGRAM_ADMIN_ID
   4. Убедитесь что нет лишних пробелов
   5. Сохраните файл
   6. Закройте черное окно и запустите заново

ПРОБЛЕМА: Не вижу файл .env
✅ РЕШЕНИЕ:
   1. Включите отображение скрытых файлов
   2. В проводнике: Вид → Скрытые элементы (включить)
   3. Теперь файл должен быть виден

🎮 ОСНОВНЫЕ КОМАНДЫ ПОСЛЕ ЗАПУСКА
═══════════════════════════════════════════════════════════════════════

Отправляйте боту эти команды:

/start      - Приветствие и информация о боте
/generate   - НАЧАТЬ генерировать видео (спросит сколько)
/status     - ПРОВЕРИТЬ статус (идет ли генерация)
/videos     - СПИСОК всех видео что были сгенерированы
/help       - СПРАВКА (все команды)
/cancel     - ОТМЕНИТЬ текущую операцию
