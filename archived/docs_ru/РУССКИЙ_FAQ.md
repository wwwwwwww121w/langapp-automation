# ❓ Часто Задаваемые Вопросы (FAQ)

---

## 🎯 ВОП РОС: КУД ДОБАВЛЯТЬ ТОКЕН?

**ОТВЕТ:**

В файл `.env` в папке `C:\langapp-automation\`

**Как его открыть:**
1. Откройте папку: `C:\langapp-automation\`
2. Найдите файл `.env` (может быть не виден, если скрыт)
3. Щелкните **правой кнопкой** → "Открыть с помощью" → "Блокнот"
4. В конце найдите:
   ```
   TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
   TELEGRAM_ADMIN_ID=your_telegram_user_id_here
   ```
5. Замените на ВАШИ значения
6. Сохраните (Ctrl+S)

---

## ❓ ВОПРОС: Я не вижу файл .env!

**ОТВЕТ:**

Файл скрыт! Нужно включить отображение скрытых файлов.

**Как это сделать (Windows 10/11):**
1. Откройте папку: `C:\langapp-automation\`
2. В верхнем меню нажмите **"Вид"**
3. Найдите опцию **"Скрытые элементы"** или "Hidden items"
4. **Включите галочку**
5. Теперь файл `.env` должен быть виден!

## ❓ ВОПРОС: Какой токен мне нужен?

**ОТВЕТ:**

Токен Телеграм бота, который вы создаете с @BotFather.

**Как его получить:**
1. Откройте Телеграм
2. Найдите @BotFather
3. Напишите: `/newbot`
4. Ответьте на вопросы
5. @BotFather даст вам ДЛИННУЮ СТРОКУ с буквами, цифрами и двоеточием
6. **СКОПИРУЙТЕ ВСЮ СТРОКУ**

Пример:
```
6123456789:ABCDEFGHIJKLMNOPQRSTuvwxyz1234567890
```

---

## ❓ ВОПРОС: Какой ID мне нужен?

**ОТВЕТ:**

Ваш личный ID в Телеграме.

**Как его узнать:**
1. Откройте Телеграм
2. Найдите @userinfobot
3. Напишите ему **любое сообщение** (даже просто "привет")
4. Бот ответит и покажет ваш **ID** - это просто число

Пример:
```
123456789
```

---

## ❓ ВОПРОС: Я скопировал токен, что дальше?

**ОТВЕТ:**

1. Откройте файл `.env` в Блокноте
2. Найдите строку: `TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here`
3. Замените `your_telegram_bot_token_here` на **ВАШ токен**
4. Пример:
   ```
   Было:
   TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
   
   Стало:
   TELEGRAM_BOT_TOKEN=6123456789:ABCDEFGHIJKLMNOPQRSTuvwxyz1234567890
   ```
5. Нажмите **Ctrl+S** (сохранить)

## ❓ ВОПРОС: Я добавил токен, но окно бота не открывается

**ОТВЕТ:**

Проверьте что вы сделали:

1. [ ] Закрыли ли вы файл `.env` после редактирования?
2. [ ] Сохранили ли файл (Ctrl+S)?
3. [ ] Добавили ли оба значения (TOKEN и ADMIN_ID)?

Если все правильно - удалите файл `.env` и заново:
```
1. Отредактируйте .env
2. Сохраните
3. Закройте его
4. Откройте Command Prompt (Win+R → cmd)
5. Напишите: python verify_farm_setup.py
6. Проверьте результат
```

## ❓ ВОПРОС: Что означает "TELEGRAM_BOT_TOKEN not set"?

**ОТВЕТ:**

Это значит, что бот не нашел токен в файле `.env`.

**Как исправить:**
1. Откройте `.env` в Блокноте
2. Проверьте есть ли строка: `TELEGRAM_BOT_TOKEN=6123456789:...`
3. Если нет - добавьте эту строку
4. Если она пуста - вставьте ВАШ токен
5. Сохраните файл
6. Перезапустите бота

---

## ❓ ВОПРОС: Бот запустился, но не отвечает на /start

**ОТВЕТ:**

Проверьте несколько вещей:

1. **Интернет:** Проверьте что интернет работает
2. **Токен правильный:** Убедитесь что вставили точный токен
3. **Окно открыто:** Убедитесь что окно бота не закрылось
4. **Правильный бот:** Убедитесь что пишете именно вашему боту (по юзернейму)

Решение:
```
1. Закройте окно бота
2. Откройте Command Prompt
3. Напишите: python verify_farm_setup.py
4. Смотрите результат
5. Если ошибка - исправьте .env
6. Запустите start_farm_mode.bat заново
```

## ❓ ВОПРОС: Как запустить бота?

**ОТВЕТ:**

Два способа:

**Способ 1: Самый простой (РЕКОМЕНДУЕТСЯ)**
1. Откройте папку: `C:\langapp-automation\`
2. Найдите файл: `start_farm_mode.bat`
3. **Дважды щелкните** по нему
4. Появится черное окно - это нормально!
5. Дождитесь: "Bot started successfully!"

**Способ 2: Command Prompt**
1. Нажмите Win+R
2. Напишите: `cmd`
3. Нажмите Enter
4. Напишите:
   ```
   cd C:\langapp-automation
   python telegram_bot.py
   ```
5. Нажмите Enter

## ❓ ВОПРОС: Видео не отправляются боту

**ОТВЕТ:**

Проверьте:
1. **Генерация завершена?** Проверьте `/status`
2. **Интернет?** Проверьте соединение
3. **Место на диске?** Может быть диск переполнен

Если все ок:
```
1. Отправьте /videos
2. Бот должен показать список
3. Если видео там - значит сгенерировались
4. Если видео не отправляются - ошибка загрузки
```

## ❓ ВОПРОС: Как я знаю что бот работает правильно?

**ОТВЕТ:**

Сделайте тест:

1. Напишите боту: `/start`
2. Бот должен ответить: "🚀 Добро пожаловать..."
3. Напишите: `/generate`
4. Бот должен спросить: "Сколько видео?"
5. Напишите: `1`
6. Бот должен начать генерировать

Если все эти шаги работают - **бот работает нормально!**

## ❓ ВОПРОС: Разница между старым веб-сайтом и новым ботом?

**ОТВЕТ:**

| Что | Веб-сайт | Бот Телеграм |
|-----|----------|-------------|
| **Интерфейс** | Браузер | Телеграм |
| **Доступ** | Через http://localhost | Только через Телеграм |
| **Порт** | Занимает порт 5000 | Не занимает порт |
| **Мобильный** | Нужен браузер | Встроенное приложение |
| **Проще** | Нет, сложнее | Да, просто команды |
| **Приватный** | Нет | Да, только вы |

**Рекомендуется:** Использовать Телеграм бот! Проще и лучше.
