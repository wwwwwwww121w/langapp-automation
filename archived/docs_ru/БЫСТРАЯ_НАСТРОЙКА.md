# ✅ Быстрая Настройка - 5 Минут

**Все что нужно сделать для запуска бота за 5 минут!**

---

## ШАГ 1️⃣: Создать Телеграм Бота (2 мин)

- [ ] Откройте **Телеграм**
- [ ] Найдите **@BotFather** (напишите в поиске)
- [ ] Отправьте ему: `/newbot`
- [ ] Ответьте на вопросы:
  - **Название:** `LinguaStart Video Farm` (или любое другое)
  - **Юзернейм:** `linguastart_farm_123` (уникальный, заканчивается на `_bot`)
- [ ] @BotFather выдаст вам **ДЛИННУЮ СТРОКУ** (токен)
- [ ] **СКОПИРУЙТЕ** эту строку

✅ **Готово! Токен скопирован!**

---

## ШАГ 2️⃣: Получить Свой ID (1 мин)

- [ ] Откройте **Телеграм**
- [ ] Найдите **@userinfobot**
- [ ] Напишите ему **любое сообщение** (например "привет")
- [ ] Бот ответит и покажет вам **ID** (просто число)
- [ ] **СКОПИРУЙТЕ** этот номер

✅ **Готово! ID скопирован!**

---

## ШАГ 3️⃣: Отредактировать .env Файл (1 мин)

**Самый важный шаг! Будьте внимательны!**

### **Способ 1: Через Блокнот (РЕКОМЕНДУЕТСЯ)**

1. [ ] Откройте папку: `C:\langapp-automation\`

2. [ ] Найдите файл **`.env`** (точка в начале - это нормально)

3. [ ] **Щелкните ПРАВОЙ кнопкой** по файлу

4. [ ] Выберите: **"Открыть с помощью"** → **"Блокнот"**

5. [ ] В конце файла найдите эти две строки:
   ```
   TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
   TELEGRAM_ADMIN_ID=your_telegram_user_id_here
   ```

6. [ ] **ЗАМЕНИТЕ** их на ВАШИ значения:
   
   **Было:**
   ```
   TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
   TELEGRAM_ADMIN_ID=your_telegram_user_id_here
   ```
   
   **Стало (ПРИМЕР):**
   ```
   TELEGRAM_BOT_TOKEN=6123456789:ABCDEFGHIJKLMNOPQRSTuvwxyz1234567890
   TELEGRAM_ADMIN_ID=123456789
   ```

7. [ ] Нажмите **Ctrl+S** (сохранить)

8. [ ] Закройте Блокнот

✅ **Готово! Файл сохранен!**

---

## ШАГ 4️⃣: Запустить Бота (1 мин)

### **Способ 1: Самый простой (ДВОЙНОЙ ЩЕЛЧОК)**

1. [ ] Откройте папку: `C:\langapp-automation\`

2. [ ] Найдите файл: **`start_farm_mode.bat`**

3. [ ] **Дважды щелкните** по нему (двойной клик)

4. [ ] Появится черное окно (это нормально)

5. [ ] Дождитесь сообщения: **"Bot started successfully!"**

6. [ ] **НЕ ЗАКРЫВАЙТЕ** это окно! Пусть остается открытым!

✅ **Готово! Бот запущен!**

---

## ШАГ 5️⃣: Протестировать (1 мин)

- [ ] Откройте **Телеграм**

- [ ] Найдите вашего бота (по юзернейму что придумали на шаге 1)

- [ ] **Нажмите** на чат с ботом

- [ ] Напишите: **`/start`**

- [ ] Нажмите **отправить**

**Если вы видите ответ от бота:**
```
🚀 Добро пожаловать в LinguaStart Video Farm!
...
```

✅ **ВСЕ РАБОТАЕТ! ВЫ ГЕНИЙ!**

---

## 📹 ПЕРВЫЙ ТЕСТ: ГЕНЕРИРОВАТЬ ВИДЕО

После того как `/start` сработал:

1. [ ] Напишите боту: **`/generate`**

2. [ ] Бот спросит: **"Сколько видео? (1-20):"**

3. [ ] Напишите: **`1`** (начните с одного!)

4. [ ] Нажмите отправить

5. [ ] **Ждите 5-10 минут** (идет процесс)

6. [ ] Бот вышлет вам **видео файл** (MP4)

✅ **ПОЗДРАВЛЯЕМ! ПЕРВОЕ ВИДЕО ГОТОВО!**

---

## ❌ ЧТО ДЕЛАТЬ ЕСЛИ ОШИБКА

### **"Bot doesn't respond" (бот не отвечает)**
```
✅ Решение:
   1. Проверьте окно бота - оно должно быть открыто
   2. Проверьте интернет
   3. Закройте окно и запустите start_farm_mode.bat заново
```

### **"TELEGRAM_BOT_TOKEN not set" (ошибка при запуске)**
```
✅ Решение:
   1. Откройте .env файл в Блокноте
   2. Проверьте что добавили TELEGRAM_BOT_TOKEN
   3. Проверьте что добавили TELEGRAM_ADMIN_ID
   4. Убедитесь что нет лишних пробелов
   5. Сохраните файл (Ctrl+S)
   6. Запустите start_farm_mode.bat заново
```

### **"Token not valid" (неверный токен)**
```
✅ Решение:
   1. Откройте Телеграм
   2. Напишите @BotFather: /mybots
   3. Выберите вашего бота
   4. Выберите "API Token"
   5. Копируйте ВЕСЬ текст (целиком!)
   6. Вставьте в .env
   7. Сохраните и перезапустите
```
