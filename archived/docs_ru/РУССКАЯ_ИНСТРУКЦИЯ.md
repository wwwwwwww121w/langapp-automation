# 🚀 LinguaStart Телеграм Бот - Русская Инструкция

## 📝 КУД ДОБАВЛЯТЬ ТОКЕН? (ОЧЕНЬ ВАЖНО!)

### **Способ 1: Самый простой (Блокнот)**

**ШАГ 1:**
Откройте папку: `C:\langapp-automation\`

**ШАГ 2:**
Найдите файл `.env` (он просто так называется, без расширения)

**ШАГ 3:**
Щелкните по нему **ПРАВОЙ КНОПКОЙ** → выберите "Открыть с помощью" → "Блокнот"

**ШАГ 4:**
В конце файла найдите эти строки:
```
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_ADMIN_ID=your_telegram_user_id_here
```

**ШАГ 5:**
Замените на СВОИ ЗНАЧЕНИЯ:
```
Было:
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_ADMIN_ID=your_telegram_user_id_here

Стало:
TELEGRAM_BOT_TOKEN=6123456789:ABCDEFGHIJKLMNOPQRSTuvwxyz1234567890
TELEGRAM_ADMIN_ID=123456789
```

**ШАГ 6:**
Нажмите **Ctrl+S** (сохранить)

✅ **ВСЕ! Токен добавлен!**

## 🤖 КАК ПОЛУЧИТЬ ТОКЕН? (4 ШАГА)

### **Способ 1: Создать нового бота**

**ШАГИ:**
1. Откройте Телеграм
2. Найдите **@BotFather** (это специальный бот для создания ботов)
3. Напишите ему: `/newbot`
4. Ответьте на вопросы:
   - Имя бота: `LinguaStart Video Farm` (любое имя)
   - Юзернейм: `linguastart_farm_bot_123` (уникальный, должен заканчиваться на _bot)
5. @BotFather даст вам **ТОКЕН** - это длинная строка с буквами и цифрами
6. **СКОПИРУЙТЕ ЭТУ СТРОКУ**

**Пример токена:**
```
6123456789:ABCDEFGHIJKLMNOPQRSTuvwxyz1234567890
```

## 👤 КАК ПОЛУЧИТЬ ADMIN ID? (2 ШАГА)

**ШАГИ:**
1. Откройте Телеграм
2. Найдите **@userinfobot**
3. Напишите ему **любое сообщение** (например, "привет")
4. Бот вам ответит и покажет ваш **ID** - это просто число
5. **СКОПИРУЙТЕ ЭТОТ НОМЕР**

**Пример ID:**
```
123456789
```

## ⚙️ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### **Бот не запускается**
```
❌ Ошибка: "TELEGRAM_BOT_TOKEN not found"
✅ Решение:
   1. Откройте .env файл
   2. Проверьте, что добавили TELEGRAM_BOT_TOKEN
   3. Проверьте, что добавили TELEGRAM_ADMIN_ID
   4. Сохраните файл
   5. Запустите заново
```

### **Бот не отвечает**
```
❌ Бот не реагирует на команды
✅ Решение:
   1. Проверьте интернет
   2. Проверьте, что окно бота открыто
   3. Проверьте значение токена в .env
   4. Запустите заново: start_farm_mode.bat
```

### **Видео не генерируются**
```
❌ Команда /generate не работает
✅ Решение:
   1. Проверьте /status (может еще идет процесс)
   2. Попробуйте /generate 1 (только одно видео)
   3. Проверьте интернет
   4. Перезапустите бота
```
