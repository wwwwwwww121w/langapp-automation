  Chat @userinfobot → Copy your ID

  Edit .env → Add TELEGRAM_BOT_TOKEN and TELEGRAM_ADMIN_ID

  Open Telegram → Find your bot → Send /start

🆘 TROUBLESHOOTING
================================================================================

Bot won't start?
  → Check .env has correct token
  → Run: python verify_farm_setup.py

Bot doesn't respond?
  → Check internet connection
  → Check logs/telegram_bot.log

Videos don't generate?
  → Check /status for progress
  → Wait (might still processing)
  → Try /generate 1 first
