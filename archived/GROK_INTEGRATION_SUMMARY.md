## 📌 ЧТО БЫЛО СДЕЛАНО

### ✅ Новый скрипт генерации сценариев

**Файл:** `scripts/01_generate_scenarios_grok.py`

Этот скрипт **заменяет** старый `01_generate_scenarios.py` и использует **Grok API** вместо Fireworks:

```python
# Старая версия (Fireworks)

client = OpenAI(api_key=FIREWORKS_API_KEY, base_url=FIREWORKS_BASE_URL)

# Новая версия (Grok)
from openai import OpenAI
client = OpenAI(api_key=GROK_API_KEY, base_url=GROK_BASE_URL)
```

**Отличия:**
- 🎯 Лучше понимает контекст
- 🌍 Отлично работает с арабским языком
- ⚡ Быстрее обрабатывает запросы
- 💰 Более доступная цена
- 📊 Более креативные сценарии

## 🆘 РЕШЕНИЕ ОШИБОК

### Ошибка: "GROK_API_KEY not set"
- Проверьте .env файл
- Убедитесь что добавили строку GROK_API_KEY=...
- Нет ли пробелов в начале

### Ошибка: "Invalid API key"
- Скопируйте ключ с сайта xAI еще раз
- Убедитесь что весь ключ (от начала до конца)
- Проверьте что нет лишних пробелов в конце

### Ошибка: "Insufficient credit"
- Перейдите на https://console.x.ai/
- Нажмите Billing
- Пополните баланс

### Ошибка: "Rate limit exceeded"
- Подождите 1-2 минуты
- Не запускайте слишком много задач одновременно
