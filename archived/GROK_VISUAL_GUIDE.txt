ШАГ 1: ПЕРЕЙТИ НА САЙТ xAI
────────────────────────────────────────────────────────────────────────────────
1. Откройте браузер (Chrome, Firefox, Edge, etc)
2. В адресной строке напишите:

   https://console.x.ai/

3. Нажмите Enter

          ┌─────────────────────────────────────────────────────┐
          │  📍 https://console.x.ai/                           │
          │                                                      │
          │  🤖 Welcome to xAI Console                          │
          │                                                      │
          │  [Sign In]  [Sign Up]                               │
          └─────────────────────────────────────────────────────┘


ШАГ 2: ЗАРЕГИСТРИРУЙТЕСЬ (если нет аккаунта)
────────────────────────────────────────────────────────────────────────────────
1. Нажмите кнопку [Sign Up]
2. Введите Email
3. Подтвердите Email
4. Установите пароль
5. Завершите регистрацию

          ┌─────────────────────────────────────────────────────┐
          │  Sign Up Form                                        │
          │  ┌────────────────────────────────────────────────┐ │
          │  │ Email: your@email.com                          │ │
          │  │ Password: ••••••••                             │ │
          │  │ Confirm: ••••••••                              │ │
          │  │ [CREATE ACCOUNT]                               │ │
          │  └────────────────────────────────────────────────┘ │
          └─────────────────────────────────────────────────────┘


ШАГ 3: ВОЙТИ В КОНСОЛЬ
────────────────────────────────────────────────────────────────────────────────
1. После регистрации вы попадете в консоль
2. В левом меню найдите "API Keys" или "Ключи API"
3. Нажмите на этот пункт

          │                                                         │

          │  ┌──────────────────────────────────────────────────┐ │
          │  │ [+ Create API Key]                               │ │
          │  └──────────────────────────────────────────────────┘ │
          │                                                         │
          └────────────────────────────────────────────────────────┘


ШАГ 4: СОЗДАТЬ НОВЫЙ API KEY
────────────────────────────────────────────────────────────────────────────────
1. Нажмите кнопку [+ Create API Key] или [Create New Key]
2. Можно дать имя ключу (например "VideoFarm" или оставить default)
3. Нажмите [Create]

          ┌────────────────────────────────────────────────────────┐
          │  Create API Key Dialog                                 │
          │  ┌──────────────────────────────────────────────────┐ │
          │  │ Key Name (optional):                             │ │

          │  │ [Cancel]  [Create]                              │ │
          │  └──────────────────────────────────────────────────┘ │
          └────────────────────────────────────────────────────────┘


ШАГ 5: СКОПИРОВАТЬ КЛЮЧ
────────────────────────────────────────────────────────────────────────────────
1. Система покажет новый ключ - ЭТО ВАЖНО!
2. Ключ выглядит так:

   sk-proj-abcdefghijklmnopqrstuvwxyz1234567890...

3. Нажмите кнопку [Copy] или [📋 Скопировать]
4. Или выделите весь ключ руками (Ctrl+A) и скопируйте (Ctrl+C)

          │                                                         │

ШАГ 6: ПРОВЕРИТЬ БАЛАНС

2. Должно быть написано:

   Account Balance: $10.00 (или сколько у вас есть)

ШАГ 7: ДОБАВИТЬ КЛЮЧ В .env ФАЙЛ
────────────────────────────────────────────────────────────────────────────────

1. Откройте папку:
   C:\langapp-automation\

          ┌─────────────────────────────────────────┐
          │  📁 langapp-automation                  │
          │  ├─ scripts/                            │
          │  ├─ output/                             │
          │  ├─ logs/                               │
          │  ├─ data/                               │
          │  ├─ telegram_bot_v2.py                  │
          │  ├─ config.py                           │
          │  ├─ .env              ← ЭТОТ ФАЙЛ ⭐    │
          │  └─ start_bot_v2.bat                    │
          └─────────────────────────────────────────┘

2. Если файл .env не видно, включите скрытые файлы:
   Вид → Скрытые элементы → ✓ включить

3. Щелкните ПРАВОЙ кнопкой по .env:
   → "Открыть с помощью" → "Блокнот"

          ┌────────────────────────────────┐
          │  📄 .env                       │
          │  📄 config.py              [✓] │
          │  📄 telegram_bot_v2.py         │
          │  ─────────────────────────     │
          │  "Открыть с помощью..."        │
          │  "Открыть в Notepad" ← СЮДА   │
          │  "Edit"                        │
          └────────────────────────────────┘

4. В Блокноте найдите:

   GROK_API_KEY=your_grok_api_key_here

5. Замените на ВАШ ключ:

   ДО:
   GROK_API_KEY=your_grok_api_key_here

   ПОСЛЕ:
   GROK_API_KEY=sk-proj-abcdefghijklmnopqrstuvwxyz1234567890

6. Нажмите Ctrl+S (сохранить)
7. Закройте Блокнот

          ┌──────────────────────────────────────────────┐
          │  📝 Notepad (.env)                           │
          │  ┌──────────────────────────────────────────┐│
          │  │# Grok API Configuration                  ││
          │  │GROK_API_KEY=sk-proj-xyz123...            ││
          │  │GROK_BASE_URL=https://api.x.ai/v1         ││
          │  │GROK_MODEL=grok-2                         ││
          │  │                                           ││
          │  │# Telegram Bot Configuration              ││
          │  │TELEGRAM_BOT_TOKEN=8616347923:AAG...      ││
          │  │TELEGRAM_ADMIN_ID=1981552297              ││
          │  │                                           ││
          │  └──────────────────────────────────────────┘│
          │  [Сохранить]  [Отмена]                      │
          └──────────────────────────────────────────────┘


ШАГ 8: ЗАПУСТИТЬ БОТ
────────────────────────────────────────────────────────────────────────────────
1. В папке C:\langapp-automation\ найдите файл:

   start_bot_v2.bat

2. Дважды щелкните по нему

          ┌────────────────────────────┐
          │ start_bot_v2.bat       [▶] │
          └────────────────────────────┘

3. Появится черное окно Command Prompt - это нормально!
4. В окне должно написать:

   "Bot started successfully!"
   или "Bot is running..."


ШАГ 9: ПРОТЕСТИРОВАТЬ В ТЕЛЕГРАМЕ
────────────────────────────────────────────────────────────────────────────────
1. Откройте Телеграм
2. Найдите вашего бота (по юзернейму, который вы создали в @BotFather)
3. Напишите: /start
4. Нажмите на кнопку: 🎬 Генерировать видео
5. Выберите: 1️⃣ 1 видео
6. Ждите...

   Должны увидеть сообщения:
   ⏳ Этап 1/3: Генерация сценариев...
   ⏳ Этап 2/3: Создание кадров...
   ⏳ Этап 3/3: Монтаж видео...
   ✅ Успешно! Сгенерировано 1 видео.

7. Вам придет видео файл - ОТЛИЧНО! 🎉
