🚀 БЫСТРЫЙ СТАРТ (для вас):

ШАГ 1: Получить API Ключ (2 минуты)
   1. Перейти на: https://console.x.ai/
   2. Создать аккаунт (если нет)
   3. API Keys → Create API Key
   4. Скопировать ключ (начинается с sk-proj-)

ШАГ 2: Добавить в .env (2 минуты)
   1. Открыть: C:\langapp-automation\.env в Блокноте
   2. Найти: GROK_API_KEY=your_grok_api_key_here
   3. Заменить на: GROK_API_KEY=sk-proj-[ваш-ключ]
   4. Сохранить: Ctrl+S

ШАГ 3: Запустить Бот (1 минута)
   1. Дважды щелкнуть: start_bot_v2.bat
   2. Дождаться сообщения о запуске

ШАГ 4: Тестировать (2 минуты)
   1. Телеграм → /start
   2. Нажать: 🎬 Генерировать видео
   3. Выбрать: 1️⃣ 1 видео
   4. Получить видео

🆘 РЕШЕНИЕ ПРОБЛЕМ:

ПРОБЛЕМА: "GROK_API_KEY not set"
РЕШЕНИЕ:
   1. Проверьте .env файл
   2. Убедитесь что есть строка: GROK_API_KEY=sk-proj-...
   3. Проверьте что нет пробелов в начале
   4. Сохраните: Ctrl+S
   5. Перезапустите бот

ПРОБЛЕМА: "Invalid API key"
РЕШЕНИЕ:
   1. Скопируйте ключ с сайта xAI еще раз
   2. Убедитесь что вы скопировали весь ключ
   3. Проверьте что нет лишних пробелов в конце
   4. Убедитесь что ключ начинается с sk-proj-

ПРОБЛЕМА: "Insufficient credit"
РЕШЕНИЕ:
   1. Перейдите на https://console.x.ai/
   2. Нажмите Billing
   3. Пополните баланс (минимум $5-10)
   4. Подождите 5 минут чтобы обновилось
   5. Попробуйте генерировать видео заново

ПРОБЛЕМА: Бот не отвечает
РЕШЕНИЕ:
   1. Закройте черное окно бота
   2. Подождите 5 секунд
   3. Дважды щелкните start_bot_v2.bat заново
   4. Дождитесь "Bot started"
   5. Попробуйте в Телеграме снова
