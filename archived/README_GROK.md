## ⚡ БЫСТРЫЙ СТАРТ

### Шаг 1: Получить API ключ (2 минуты)
```
1. Перейти на https://console.x.ai/
2. Создать аккаунт
3. Перейти в API Keys
4. Нажать Create API Key
5. Скопировать ключ (sk-proj-xxx...)
```

### Шаг 2: Добавить в .env (2 минуты)
```
1. Открыть: C:\langapp-automation\.env в Блокноте
2. Найти: GROK_API_KEY=your_grok_api_key_here
3. Заменить на: GROK_API_KEY=sk-proj-xxx...
4. Сохранить: Ctrl+S
5. Закрыть
```

### Шаг 3: Запустить бот (1 минута)
```
1. Дважды щелкнуть: C:\langapp-automation\start_bot_v2.bat
2. Дождаться "Bot started successfully!"
3. Открыть Телеграм
4. Написать /start
5. Нажать 🎬 Генерировать видео
```

### Шаг 4: Проверить (2 минуты)
```
1. Выбрать количество: 1️⃣ 1
2. Ждать генерации
3. Получить видео
4. ✅ Готово!
```

**Итого: 7 минут и все работает!** ⚡

