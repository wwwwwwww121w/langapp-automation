```
✅ Эффективно, качественно, быстро
```

- ✅ **Тестирование** - юнит-тесты, интеграционные тесты
- ⚡ **Оптимизация** - производительность, кэширование
- 🎓 **Стратегия** - долгосрочное развитие проекта

**Пример моей работы:**

### 🤖 GROK (помощник) - ПОМОЩНИК

**Отвечает за:**
- 📚 **Документация** - README, гайды, инструкции
- 🎨 **Дизайн** - UI элементы, макеты, эстетика
- 🛠️ **Утилиты** - helper функции, вспомогательные скрипты
- ⚙️ **Конфигурация** - setup файлы, ENV переменные
- 📝 **Примеры** - примеры использования, демо-код
- 📖 **Форматирование** - структурирование текста, эмодзи

**Пример работы Grok:**

## 📋 ТИПЫ ЗАДАЧ И РАСПРЕДЕЛЕНИЕ

### 🔴 CRITICAL (только Claude)
```
❌ Не делегируется Grok
✅ Всегда делает Claude

Примеры:
• Архитектура системы
• Core API интеграции
• Безопасность
• Критичные баги
• Оптимизация производительности
```

### 🟠 HIGH (обычно Claude, иногда Grok)
```
Правило: Если > 100 строк кода или сложная логика → Claude
         Если утилита или конфиг → Grok

Примеры:
• Новые функции в боте → Claude
• Setup инструкции → Grok
• Обработка ошибок → Claude
• Helper функции → Grok
```

### 🟡 MEDIUM (Grok, если в его категории)
```
Делегируется Grok:
• Документация
• Примеры
• Форматирование
• Простые скрипты

Делает Claude:
• Логика с интеграциями
• Обработка данных
• Оптимизация
```

### 🟢 LOW (в основном Grok)
```
✅ Обычно делегируется Grok

Примеры:
• FAQ
```
