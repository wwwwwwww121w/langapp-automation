# ⚡ Grok - БЫСТРАЯ НАСТРОЙКА (5 минут)

## 📋 Чеклист

- [ ] **1. Перейду на** https://console.x.ai/
- [ ] **2. Создам API Key** (копирую ключ)
- [ ] **3. Откроюю .env** в Блокноте
- [ ] **4. Добавлю ключ**:
  ```
  GROK_API_KEY=sk-proj-xxxx...
  ```
- [ ] **5. Сохраню** (Ctrl+S)
- [ ] **6. Запущу** `start_bot_v2.bat`
- [ ] **7. Тест:** нажму 🎬 → выберу 1 видео
- [ ] ✅ **ГОТОВО!**

---

## 🔑 ГДЕ ВЗЯТЬ API KEY?

### 1️⃣ Сайт xAI
```
https://console.x.ai/
→ API Keys
→ Create API Key
→ Скопировать весь ключ
```

### 2️⃣ Ключ выглядит так:
```
sk-proj-abcdefghijklmnopqrstuvwxyz123456789...
```

### 3️⃣ Проверка баланса:
На странице API должно быть: `Account Balance: $10.00`

---

## 📝 ДОБАВИТЬ В .env

### Открыть файл:
```
C:\langapp-automation\ → .env → Блокнот
```

### Найти:
```
GROK_API_KEY=your_grok_api_key_here
```

### Заменить на:
```
GROK_API_KEY=sk-proj-123456789...xyz
```

### Сохранить:
```
Ctrl+S → Закрыть
```

## ❌ ЕСЛИ ОШИБКА

| Ошибка | Решение |
|--------|---------|
| **"GROK_API_KEY not set"** | Перепроверьте .env, сохраните |
| **"Invalid API key"** | Скопируйте ключ с сайта еще раз |
| **"Insufficient credit"** | Пополните баланс на https://console.x.ai/ |
| **"Connection error"** | Проверьте интернет |
