## ✨ ЧТО НОВОЕ?

**Переход на Grok нейросеть!**

Мы заменили Fireworks на Grok для **более умной генерации сценариев**:

- ✅ Более креативные сценарии
- ✅ Лучше работает с арабским языком
- ✅ Быстрее обрабатывает запросы

## 📋 ШАГ 1: Получить Grok API ключ

### Способ 1: Через сайт xAI (РЕКОМЕНДУЕТСЯ)

1. Перейдите на: https://console.x.ai/
2. Зарегистрируйтесь (если нет аккаунта)
3. В левом меню нажмите **"API Keys"** или **"Ключи API"**
4. Нажмите кнопку **"Create API Key"** или **"Создать ключ API"**
5. Скопируйте полученный ключ (выглядит так: `sk-proj-xxx...xxx`)
6. **СОХРАНИТЕ ЭТО ЗНАЧЕНИЕ!** Оно больше не будет показано!

### Способ 2: Проверить баланс

1. На странице API Keys должно быть написано:
   ```
   Account Balance: $x.xx
   ```
2. Убедитесь что есть кредиты (минимум $5)

---

## 🔧 ШАГ 2: Добавить ключ в .env

### Как открыть .env файл:

1. Откройте папку: `C:\langapp-automation\`
2. Если файл `.env` не видно - включите отображение скрытых файлов:
   - Нажмите **Вид** → **Скрытые элементы** → включите галочку
3. Правой кнопкой по файлу `.env` → **"Открыть с помощью"** → **"Блокнот"**

### Найдите строку:

```
GROK_API_KEY=your_grok_api_key_here
```

### Замените на ваш ключ:

**ДО:**
```
GROK_API_KEY=your_grok_api_key_here
```

**ПОСЛЕ:**
```
GROK_API_KEY=sk-proj-abcdef123456789...
```

### Сохраните файл:
- Нажмите **Ctrl+S**
- Закройте Блокнот

## ⚙️ ПЕРЕМЕННЫЕ КОНФИГУРАЦИИ (опционально)

### Если нужно изменить модель Grok:

Откройте `.env` и добавьте:

```
# Какая модель использовать (опционально)
GROK_MODEL=grok-2

# API endpoint (обычно не меняется)
GROK_BASE_URL=https://api.x.ai/v1
```

**Доступные модели:**
- `grok-2` - самая новая и мощная (РЕКОМЕНДУЕТСЯ)
- `grok-vision` - с поддержкой изображений (если нужна)

## 🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Ошибка: "GROK_API_KEY not set"

**Значит:** Ключ не найден в файле `.env`

**Решение:**
1. Проверьте что добавили `GROK_API_KEY=sk-proj-...`
2. Проверьте что нет пробелов спереди
3. Сохраните файл (Ctrl+S)
4. Перезапустите бот (закройте и откройте заново)

### Ошибка: "Invalid API key"

**Значит:** Ключ неправильный или неверный формат

**Решение:**
1. Скопируйте ключ с сайта еще раз
2. Убедитесь что вы скопировали **весь** ключ (от начала до конца)
3. Проверьте что в .env НЕТ лишних пробелов в конце
4. Проверьте что ключ начинается с `sk-proj-`

### Ошибка: "Insufficient credit"

**Значит:** Закончились кредиты в аккаунте Grok

**Решение:**
1. Перейдите на https://console.x.ai/
2. Нажмите **Billing** или **Платежи**
3. Пополните баланс (добавьте $10-50)
4. Подождите 5 минут чтобы обновилось
5. Попробуйте генерировать видео заново

### Ошибка: "Rate limit exceeded"

**Значит:** Много запросов в одну минуту

**Решение:**
1. Подождите 1-2 минуты
2. Попробуйте генерировать медленнее
3. Не запускайте несколько ботов одновременно
