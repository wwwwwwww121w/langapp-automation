# Ответ по Runway ML Interface

> **Честное предупреждение:** Я могу дать общую информацию, но точные CSS-селекторы и актуальное состояние UI могли измениться. Runway активно обновляет интерфейс.

## 1. Вход в систему ✅
```json
{
  "login_url": "https://app.runwayml.com/login",
  "workspace_url": "https://app.runwayml.com",
  "projects_url": "https://app.runwayml.com/projects",
  "auth_required": true
}
```

## 2. Интерфейс генерации видео

### Общая схема (актуальная на 2024/2025):
```
Лендинг → Projects → Create New → Gen-3 Alpha Turbo (или Gen-2)
```

### Модели (из того что известно):
- **Gen-3 Alpha** — флагман, текст→видео, высокое качество
- **Gen-3 Alpha Turbo** — быстрая версия
- **Gen-2** — предыдущее поколение

### Поля в интерфейсе обычно включают:
- **Prompt** (textarea) — текстовое описание
- **Duration** — длительность (обычно 5-10 сек)
- **Aspect ratio** — 16:9, 9:16, 1:1, 4:3
- **Motion** — управление движением камеры (иногда)

### ⚠️ Важное ограничение:
**Бесплатный тариф обычно даёт ограниченное количество генераций ("credits").** Точные лимиты меняются — проверяйте актуальные условия на сайте.

## 4. Кнопки и статусы

- Кнопка: обычно **"Generate"** или **"Create"** → **"Generate video"**
- Статусы: **Queued → Processing → Completed**
- Прогресс: progress bar или процент
- Скачивание: кнопка **"Download"** на карточке результата

## 5. CSS селекторы — ⚠️ ПРЕДУПРЕЖДЕНИЕ

> **Я НЕ могу дать точные актуальные селекторы.** UI Runway постоянно меняется. Вот что могу предложить:

### Подход через Playwright:
```javascript
// Вместо жёстких селекторов используйте:
// 1. Текстовый поиск
await page.getByText("Generate").click();
await page.getByPlaceholder("Describe your video").fill(prompt);

// 2. Общие атрибуты
await page.locator('textarea').first().fill(prompt);
await page.locator('button:has-text("Generate")').click();

// 3. Запасной вариант — селектор по role
await page.getByRole("button", { name: /generate/i }).click();
```

### Причина проблемы:
Runway использует React с динамическими class names (например, `css-1abc123`), поэтому жёсткие CSS-селекторы ломаются после каждого обновления.
