❓ COMMON QUESTIONS
════════════════════════════════════════════════════════════════════════════════

Q: Do I need an API key?
A: No! That's the whole point. Uses your real Grok account via browser.

Q: Will I need to log in every time?
A: No, only on first run. Session is saved in ~/.grok_browser/

Q: Is it slower than API?
A: Slightly slower (5-10s vs 2-3s per question), but more reliable and transparent.

Q: Is it secure?
A: Yes! No API keys stored, uses HTTPS, real account authentication.

Q: What if it breaks?
A: Read BROWSER_INTEGRATION_GUIDE.md troubleshooting section.

Q: Can I use multiple accounts?
A: Yes, create multiple instances with different user_data_dir.

Q: What about rate limiting?
A: Add delays between requests: await asyncio.sleep(20)

For more Q&A, see:
  BROWSER_INTEGRATION_GUIDE.md → FAQ section

📞 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: "ModuleNotFoundError: No module named 'playwright'"
Solution:
  pip install playwright
  playwright install chromium

Problem: "Browser window doesn't open"
Solution:
  Set headless=False in the code to see what's happening
  See: BROWSER_INTEGRATION_GUIDE.md → Configuration

Problem: "Login fails or selector not found"
Solution:
  1. Check your internet connection
  2. Verify console.x.ai loads manually
  3. Run with headless=False to see the form
  4. See: BROWSER_INTEGRATION_GUIDE.md → Troubleshooting

Problem: "Empty response from Grok"
Solution:
  1. Add delays between requests
  2. Simplify the prompt
  3. Check your internet
  4. See: BROWSER_INTEGRATION_GUIDE.md → Troubleshooting
