Example 1: Manual Testing
───────────────────────────────────────────────────────────────────────────────
import asyncio
from grok_browser_delegate import GrokBrowserDelegate

async def test():
    grok = GrokBrowserDelegate(headless=False)  # See the browser
    await grok.setup()
    await grok.login_if_needed()

    response = await grok.ask_question("Hello, Grok!")
    print(response)

    await grok.close()

asyncio.run(test())

⚠️ IMPORTANT
════════════════════════════════════════════════════════════════════════════════

1. First run takes longer:
   - Browser needs to load
   - You'll need to log in (only happens once)
   - Session is saved for future runs

2. Browser session saved in:
   ~/.grok_browser/Default/

   Don't delete this folder if you want to stay logged in!

3. Slower than API but more reliable:
   - API: ~2 seconds per question
   - Browser: ~5-10 seconds per question
   - But browser is more transparent and reliable

4. For production, use headless mode:
   grok = GrokBrowserDelegate(headless=True)  # No visible window

🐛 QUICK TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: "Playwright not installed"
Solution:
  pip install playwright
  playwright install chromium

Problem: "Browser window doesn't open"
Solution:
  Use headless=False to see what's happening:
  grok = GrokBrowserDelegate(headless=False)

Problem: "Login fails"
Solution:
  1. Check your internet
  2. Verify console.x.ai loads manually
  3. Check if 2FA is enabled
  4. Run with headless=False to see form

Problem: "No response from Grok"
Solution:
  1. Check network connection
  2. Wait between requests (add delays)
  3. Simplify the prompt
  4. Check logs for errors

For detailed troubleshooting, see:
  BROWSER_INTEGRATION_GUIDE.md → Troubleshooting section

💡 PRO TIPS
════════════════════════════════════════════════════════════════════════════════

1. First login:
   - Use headless=False to see the login form
   - Manually log in to console.x.ai in the browser
   - Session will be saved

2. Batch processing:
   - Multiple questions in one session are faster
   - Don't close the browser between questions

3. Error handling:
   - Add delays between requests: await asyncio.sleep(20)
   - Catch exceptions for production use

4. Debugging:
   - Use headless=False to see what's happening
   - Check logs in logs/ directory
   - Review browser console for JS errors
