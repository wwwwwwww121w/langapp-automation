🔧 IMPLEMENTATION
════════════════════════════════════════════════════════════════════════════════

STEP 1: Update .env file
────────────────────────────────────────────────────────────────────────────

Add/Update these lines:

   VIDEO_WIDTH=1440
   VIDEO_HEIGHT=2560
   SECONDS_PER_FRAME=3.5
   VIDEO_CRF=18
   VIDEO_PRESET=slow
   VIDEO_CODEC=libx264


STEP 2: Delete old frames
────────────────────────────────────────────────────────────────────────────

Old frames won't work with new resolution. Delete them:

   Windows: del /s output\frames\*.png
   Linux:   rm -r output/frames/*


STEP 3: Run pipeline
────────────────────────────────────────────────────────────────────────────

Run as normal:

   python scripts/01_generate_scenarios_grok.py
   python scripts/02_generate_frames.py
   python scripts/03_assemble_videos.py

Done! Videos will now be high quality and longer.
