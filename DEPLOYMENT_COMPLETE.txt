3. Новый проект: Deploy from GitHub

5. Добавь переменные окружения:
   - TELEGRAM_BOT_TOKEN
   - TELEGRAM_ADMIN_ID
   - XAI_API_KEY
   - XAI_VIDEO_MODEL
   - И остальные (см. документацию)
6. Нажми: Deploy

🔑 НЕОБХОДИМЫЕ КЛЮЧИ
═══════════════════════════════════════════════════════════════════════════════

1. TELEGRAM_BOT_TOKEN
   Где получить: https://t.me/BotFather (команда /newbot)

2. TELEGRAM_ADMIN_ID
   Это твой ID в Telegram (получается после /start в боте)

3. XAI_API_KEY
   Где получить: https://console.x.ai
   Префикс: xai-

4. FIREWORKS_API_KEY (опционально)
   Где получить: https://fireworks.ai
   Для дополнительных функций

═════════════════════════════════════════════════════════════════════════════
🔍 КАК РАБОТАЕТ БОТ
═════════════════════════════════════════════════════════════════════════════

Пользователь в Telegram:
1. Отправляет /start
2. Видит меню с кнопками
3. Нажимает "🎬 Генерировать видео Grok"
4. Бот вызывает скрипт 04_generate_videos_via_grok.py
5. Скрипт обращается к xAI Grok API
6. Генерируются 3 видео про LinguaStart
7. Видео сохраняются в облаке xAI
8. Бот отправляет ссылки пользователю
9. Пользователь скачивает видео
10. Загружает на TikTok/Instagram Reels

Всё это происходит БЕЗ УЧАСТИЯ ЛОКАЛЬНОГО ПК!
